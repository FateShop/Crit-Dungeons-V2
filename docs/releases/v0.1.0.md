# Crit Addons v0.1.0

Minecraft **26.2**, **JDK 25**, **NoammAddons 1.3.5 cheat**. This increment provides the live map viewer and safe shared session controls. Room travel, mob clearing, secret collection, automatic modes and Blood Camp are unavailable. No boss combat is implemented.

## Additions

- Crit Addons menu category with a configurable default **M** dungeon map popup. The centered popup reuses Noamm's actual room discovery, identities, colors and renderer; unavailable information stays unknown.
- Existing Noamm notifications name disabled Dungeon Map, Map Enabled and Cheater Map prerequisites.
- Shared task control contracts with FIFO ownership, Esc stop/queue clearing, same-run stop latch, independent GUI/manual/focus/death pauses, actual-state revalidation and boss/end/exit/disconnect termination.
- Exclusive Crit resource leases and read-only coexistence with Noamm's supported ActionUtils queue boundary. Crit cancellation never resets that shared queue.

## Changes

- The template category/example feature has been replaced with the Crit Addons viewer. The addon preserves Noamm's saved keybind/configuration workflow.
- Runtime tasks stay ephemeral. Persistent mode preferences are separate from stop state; later mode controllers consume these contracts.

## Removals

- Removed the template automatic-sprint example and example client logging.

## Install and build

Install the downloadable **26.2 cheat JAR** beside the required NoammAddons 1.3.5 26.2 cheat dependency and its normal Fabric dependencies. Remove any previous version of this same addon before installing; retain existing Noamm data/settings. New features/settings appear under Crit Addons. Default M opens the popup; the configured popup key closes it; Esc cancels Crit work and dismisses screens normally. Room actions remain unavailable and clicks do not launch later gameplay.

Source: https://github.com/FateShop/Crit-Dungeons-V2/tree/v0.1.0 . Build with Microsoft JDK 25.0.1 using `.\gradlew.bat :26.2:controlTest :26.2:build`; final archive is in `build/libs`. Run `powershell -NoProfile -File scripts/Verify-Phase1.ps1` and `scripts/Verify-Release.ps1 -Stage Candidate` for reproducible checks. Source SHA, JAR hash/size, exact target and downloaded-asset checks are recorded in `v0.1.0-evidence.json`. No 26.3 release asset is supplied.

Noamm contracts were checked against installed dependency SHA-256 `6212888ddce467fb0da81bc3df9e285c39867fc8aa9547bb4976eec911f3f6fd` and pinned Noamm source `460cfaf5d8760fa1146f5d2433715b7eca9bf319`. No historical custom projects were inspected or reused.
